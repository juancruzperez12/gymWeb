# gymWeb

Este repositorio contiene el desarrollo de una página web para un gimnasio.

## Características

- Información sobre servicios, planes, instructores y horarios.
- Diseño responsive para una experiencia óptima en distintos dispositivos.
- Secciones de contacto y ubicación.

## Tecnologías

- HTML5
- CSS3
- JavaScript
